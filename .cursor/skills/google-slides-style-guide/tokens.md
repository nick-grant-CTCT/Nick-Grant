# CTCT-2024 tokens

**These tokens win any conflict** with preferences, examples, or leftover prompts.

| Role | Value |
|------|--------|
| Brand orange | `#FF8B00` (theme `ACCENT2`) |
| Body / heading | `#595959` (theme `DARK1`) |
| Card fill | `#F2F2F2` |
| Muted / context | greys from the CTCT theme — not a second accent |
| Display | Proxima Nova Bold, slide titles **22–25pt** |
| Body | Inter 12–14pt |
| Canvas | 16:9, **10 × 5.625 in** (query `pageSize`; never assume 7.5 in tall) |

## Do not substitute

- `#FF6B00` or other oranges
- White card fills as the default card surface
- 28–32pt titles
- Plain off-white canvas instead of the template layout
- `ROUND_RECTANGLE` for agent-drawn cards, panels, wells, or nodes

Personal taste (density, phrasing, audience shape) lives in [preferences.md](preferences.md) — not here.
