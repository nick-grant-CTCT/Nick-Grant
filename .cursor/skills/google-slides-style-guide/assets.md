# Assets and icons

- Prefer **isometric product PNGs** from the CTCT product-components Drive library when the slide **names** that product.
- Missing art is better than the wrong product.
- Do not use devices-library SVGs or monoline template chips when a matching isometric exists.
- Do not reuse `EC520` / `WIN10 Display` / `Radio Antenna` as decoration.
- No emoji. No letter hex chips as icons.

Wire concrete Drive folder IDs here when syncing from the full personal skill install (`assets.md` library table). Until then, resolve icons via the existing Drive product-components library the builder already uses.
